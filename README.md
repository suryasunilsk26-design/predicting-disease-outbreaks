Project Description

This project focuses on predicting polio disease outbreaks using historical disease data and machine learning techniques.

Objective

To analyze historical polio cases and predict future disease outbreaks.

Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- TensorFlow
- GRU and LSTM
Project Features
- Data preprocessing
- Exploratory Data Analysis
- Time-series analysis
- Disease case prediction
- Prediction visualization
